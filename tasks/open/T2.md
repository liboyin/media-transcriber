# T2: Host checks

**Priority:** Low.

Host checks for changes that need a Docker daemon, a real accelerator or real host data, which the devcontainer lacks ([DESIGN section 9](../../DESIGN.md#9-deployment-and-development-environment)). Each run needs the user's authorization. Paths: none. Results go into the relevant completion records. Validation: the user reports each outcome, or the main agent records the run it was authorized to make. Dependencies: the tasks whose checks it collects.

## Devcontainer

From [T1](../closed/T1.md#host-checks): on a Mac host, rebuild the devcontainer through VS Code and confirm that the creation hook clones the shared tools to `$HOME/persist/agent-workflow-common`, exposes `/workspaces/agent-workflow-common`, and installs Claude Code and Codex. After a second rebuild, confirm that their history and sign-in persist on `dev_persist`. Only amd64 or arm64, whichever the host is, is verified.
