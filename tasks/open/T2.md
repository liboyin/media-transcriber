# T2: Host checks

**Priority:** Low.

Host checks for changes that need a Docker daemon, a real accelerator or real host data, which the devcontainer lacks ([DESIGN section 9](../../DESIGN.md#9-deployment-and-development-environment)). Each run needs the user's authorization. Paths: none. Results go into the relevant completion records. Validation: the user reports each outcome, or the main agent records the run it was authorized to make. Dependencies: the tasks whose checks it collects.
