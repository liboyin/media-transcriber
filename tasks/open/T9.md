# T9: Benchmark command and result sets

**Priority:** Medium.

Outcome: the benchmark subcommand of [DESIGN section 7](../../DESIGN.md#7-benchmark), with recordings named on the command line and cold and warm timings through the shared pipeline function. It measures time only, with no energy, memory or quality measures. Every real run is a host check (T2). Paths: `media_transcriber/`, tests, README. Dependencies: T3 and at least one of T4 and T5.
